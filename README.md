# 💰 Expense Tracker CLI

A simple command-line expense tracker written in **pure Python** — no external libraries, no database. Your expenses are saved to a local `expenses.json` file so they persist between runs.

Built as a beginner-friendly project to practice file I/O, JSON, and CLI menus.

---

## ✨ Features

- ➕ **Add** an expense (amount, category, optional note)
- 📋 **List** all recorded expenses
- 📊 **Summarize** spending by category
- 🗑️ **Delete** an expense by number
- 💾 **Persistent storage** via `expenses.json`
- 🪶 **Zero dependencies** — only the Python standard library

---

### Requirements

- Python **3.7+** ([download](https://www.python.org/downloads/))
